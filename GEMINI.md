# Weezard Workspace Guidelines

Please refer to and strictly enforce all guidelines specified in [AGENTS.md](./AGENTS.md) and `.agents/rules/*.md`:
1. **No git add / commit / push** (only `git status` allowed).
2. **Modular, small component files** for every section and feature.
3. **Clean code with helpful comments** throughout.
4. **Always plan and obtain user approval** before executing code changes.
5. **Strict design fidelity** matching Figma tokens, typography, and responsive layouts.
